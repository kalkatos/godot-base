# Project: SOCSIM

A soccer autobattler that simulates a compressed version of a soccer match to be watched.

- It is not a game that will be played in any wat, just watched on stream platforms. All control belongs to an admin user (myself).
- It should be possible to render a team's strength into a set of variables that can be tweaked to influence each team's power to defeat the opponent.
- Each team will be saved to a local database and accessed to define the outcome of each match.
- Luck must have a moderate influence in a match's outcome (as it generally does on real soccer matches).
- The aim is to have 10 minute matches (two halves of 5 minutes).
